## 规则边界修复

回归覆盖了以下实际问题：

- 小队某单位在命令途中阵亡后，仍执行幸存单位的订单；混入活着的敌军仍整体拒绝。
- 军犬无法被手动命令攻击车辆；工程师只能占领/修复建筑。捕获生产建筑取消旧队列时，退款给原所有者。
- 最后一座非围墙建筑丢失的同一逻辑步完成败方清理。
- 建造健康按累计整数比例增长，未受损建筑满血完工，同时保留施工中的战斗伤害。
- 被围住的早期单位不会永久占满寻路预算。
- 大厅离开后重新分配连续开局席位；加载期间掉线会释放就绪屏障并记录规范投降。
- 最终确认后的在途输入不会导致误报；关闭 ENet 期间避免继续轮询非活跃 peer。

## 性能实测与限制

最新 1,600 单位、600 逻辑步计时（模拟执行，含寻路、经济、战斗和迷雾）：

| 指标 | 耗时 |
| --- | ---: |
| P50 | 18.0571 ms |
| P95 | 53.7150 ms |
| 最大单步 | 110.7862 ms |
| 全部计时区间 | 13,276.1701 ms |

20 Hz 的单步预算为 **50 ms**。P95 仍略超预算，机器报告明确标记 `p95WithinBudget: false`；功能检查通过不代表大军团已达到稳定实时性能。模拟 Debug 构建启用优化，并将迷雾逐像素圆判断替换为结果相同的扫描行填充后，P95 从本次此前记录的约 152.5 ms 降至约 53.7 ms；仍有进一步优化空间，不能推导 GPU 帧率。
