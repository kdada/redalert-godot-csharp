# 经典开局可玩 AI

实现位于[PracticeCommander](/storage/Users/currentUser/dev/redalert-godot-csharp/Simulation/PracticeCommander.cs)，保持 `static IEnumerable<GameCommand> Orders(World,int)` 接口。Replay 的旧同名类由 sidebar 移除。本文件仅新增原创决策逻辑，没有导入或复制原游戏引擎或原 AI 实现；目标是经典地图上能发展、生产和作战，不声称复刻原版 AI 算法或难度。

源码已完整交 Lead 并冻结，供集中 build/native 回归。此报告描述代码的确定行为与已完成的接口审查；本任务没有自行 build 或启动游戏，实际运行结论应以 Lead 的集中验证为准。

## 发展与权威规则

- 经典 MCV 开局在 Tick0 即获得一次决策。没有建造场时，按原国家地基尺寸寻找已探索且可连通的合法部署区，避开水、坡、原矿、原有建筑和其他实体碰撞。探索最多 512 个节点、距当前位置 12 格；若部队挡住原部署区，先移开己方地面部队。测试地基不临改 MCV 的生命值或玩家生产状态。最终部署仍由现有 Deploy 命令验证。
- 建序优先发电、炼厂、兵营、重工、雷达、维修厂；有合法岸边地基再造船坞，然后实验室。发电量不足以覆盖下一步消耗时优先补电，科技允许时可采用核电。电量预算使用己方完整发电建筑的有效生命值比例，避免临时间谍断电被误判为永久缺少发电站。
- 保留下一经济/科技设施的资金。后期有余款再补第二炼厂、基础地面/防空防御、经济和支援设施。防御选择受国家与科技约束，法国巨炮等独有建筑不会通过假设阵营来强行建造。
- BuildingReady 时逐候选调用 World.CanPlaceBuilding，使用真实水陆、坡、探索、实体、盟友邻接和科技规则。尚未准备好时，该接口按设计拒绝任何地基，因此排队前仅用公开地基/探索/邻接规则作保守预搜，真正 Build 仍必须通过权威接口。船坞缺少合法近岸位置时跳过，不让宏观发展一直等一张无法放下的海军建筑。
- 每次地基搜索最多 1200 个候选，最多两次搜索，优先紧凑基地；炼厂偏向已探索矿区，避开工厂和卸矿出口附近的地基。就绪建筑遇到己方部队占位时尝试疏散；几何上确实无地可放时周期性取消并全额回收，腾出建造栏。
- 所有生产请求调用 World.CanQueueBuilding / CanProduceBuilding / CanTrainUnit，并遵守工厂类别、工厂原国家、科技、国家限制、BuildLimit 和原地图 TechLevel=-1。Defcon 6 的船坞禁令由现有地图规则与真实地基接口保留。

## 经济与混合生产

- 有炼厂及已探索矿区时补合理矿车，目标每炼厂两辆、最多六辆，并把既有单位和队列都计入。丢失建造场后优先经真实科技/工厂生产替代 MCV。已收取的建筑费用不会重复扣；本次决策的多条训练命令共用本地可用资金预算。
- 非必要部队保留至少 800 或下一关键设施费用；矿车和 MCV 的恢复优先于普通军队。低电力/间谍断电时停止新排普通军队。
- 步兵、车辆、机场飞机和海军各有原创的确定选择轮换，包含当前国家实际可生产的基础兵种和特种兵种；可用性逐工厂检查，不按枚举存在就默认能训练。Kirov 等飞行车辆通过实际生产类别进入重工，Harrier/BlackEagle 遵守机场机位。
- 一次决策最多排两名单位；每工厂按已有队列加本次计划限定两项。作战单位预算上限为 80，并计入当前队列、既有克隆积压和已排步兵将来的克隆副本；连尚在建造/准备的己方克隆设施也保守计入。总单位与待产预算另留 16 个矿车/MCV/运输位置，核心 MaxEntities 仍最后约束。
- 有足够己方步兵时允许最多两个运输单位。不会训练一批工程师/间谍而假定它们可以执行普通坦克射击。

## 视野、海空与运输

直接攻击目标只能来自当前真实可见敌方单位/建筑，潜艇使用 ClassicUnitVisibleTo 的探测规则，间谍使用表面归属；每个攻击成员还必须通过 World.CanTarget。没有可见目标时，只用地图公开的起点作侦察/推进目标，不从迷雾里的敌人实际位置选择目标。静态地图通行数据用于地形规划，矿/岸边建造估值只取已探索区域。

- 陆军保留开局短暂部署保护期，八秒后允许单个快速侦察兵，随后按可用军队形成至多 20 人的小组；优先应对靠近基地的可见威胁。已在走向目标的队伍不因相同巡逻令每次重置路径。
- 海军从自身位置做最多 2048 节点的真实连通水域推进，不发给它们一个内陆步兵集结格。长程对岸攻击如果无法取得合法水面接近点，则在水面推进，让现有射程与自动战斗规则决定能否开火。
- 空军使用空域导航，飞机返航补弹时不被新攻击令反复打断；无弹飞机不参加新的出击选择。各单位的对空、对地和潜艇目标资格由现有战斗规则最终决定。
- 运输独立执行 EnterTransport → 等候正在登载者 → 向敌方起点方向渡运 → 附近有可用陆地时 Unload。新装载者在本次决策中保留，不会又被后续陆军命令覆盖登载。空载且远离基地的运输返回基地，再接下一批步兵。它是基础运输启发式，不声称拥有完整海岸战役规划。

## 预算与复现

默认每 64 Tick（20 TPS 下约 3.2 秒）一次决策，按玩家 ID 错开；Tick0 例外允许所有开局 MCV 及时行动。每次最多六条命令，每次最多两个训练请求，组命令最多 20 个作战实体。核心寻路预算仍负责最终路径计算。局部地形搜索均有限，不会在每 Tick 对每个单位重跑全图寻路。

序列严格为 `world.Tick * 100 + i`，玩家 ID 仍由命令字段区分。选择由当前 world 快照、Tick 和已排序实体 ID 决定；不存在跨 Tick 的私有随机种子、计数器或可重放记录之外的 AI 状态。临时 Decision 对象只承载当前调用的资金、已分配实体和命令预算。

已完成只读 API 核对：Rules.BuildingRequirements、World.NearestFree 的 domain/amphibious 参数、World.UnitCollisionRadius、World.BuildingAreaHasUnits、World.CanTarget、World.ClassicUnitVisibleTo、World.ClassicApparentOwner、World.CanUseBuildingFootprint、World.HasClassicAircraftSlot，以及当前玩家/运输/克隆字段。曾发现通用移动命令先按默认 Land 寻找位置的问题，已报告并由 Lead 修正权威命令路径，AI 未私改核心。

建议 Lead 集中验证经典无初始建筑开局能实际完成部署→电厂→炼厂→出矿车→重工；Defcon 禁造船坞；海图船坞与船只水域移动；飞机补弹；一次运输渡运；低资金与低电力不反复排非法命令；相同初始设置及命令流重跑得到相同 hash。这里没有把这些建议写成已经运行通过的原生结果。

## 已完成的独立静态审查

独立只读审查未发现默认开局的关键部署/经济失败或缺失 API。Lead 完成首轮原生光标回归、开放下一次源码集成窗口后，以下五个条件边界已经集中修正，再次交回 SOURCE STABLE：

- 明确攻击组先按 CanTarget 过滤再取 20 人，防止前 20 名无法对空时漏掉更远的防空单位；没有具体目标时，先筛可调度的空闲/阻塞单位再限组人数。
- 运输候选限定 Land 步兵，Infantry=true 的 Rocketeer 不再进入拒载命令或被 assigned 占用。
- 运输选择按当前 Tick 与玩家 ID 确定轮转，后来生产的第二艘运输也能获得决策。
- 既有步兵队列提前计入未来克隆产出；新训练与既有队列采用同一份副本预算。
- 原建序及资金保留统一经 NextAllowedStep 跳过禁止/国家不允许项目，再使用真实前置条件。自定义图禁 ServiceDepot 时，不再阻止仍可生产的独立实验室、船坞或防御；可选二炼厂/防空也不因被禁而占住建序。当前五张原图仅禁可选船坞，保留原规则。
