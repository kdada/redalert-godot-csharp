# 原版风格 UI 与地图调整

2026-10-18，根据“UI 和地图不像原版”的反馈，替换了最影响整体观感的程序地面与绿色列表式战场界面。

## 画面变化

- 地面改用原版 60×30 TMP 像素与 `isotem.pal`，保留 8 种草地变体、完整 7×4 粗糙地面模板和水面。地面不再绘制常驻网格线；建筑、步兵和车辆与地砖统一按原始像素比例绘制。
- 矿石、中心阻挡区域的树木和岩石采用原版 SHP。地图通行与模拟数据保持原样；树石只替换已有不可通行岩石格的外观。
- 左侧战场占满高度，右侧为 252 逻辑像素侧栏。两阵营分别使用原版 radar、side1/2/3、repair/sell 和 tab00–03；原版雷达打开动画末帧的屏幕范围通过索引像素测量，避免小地图覆盖边框。
- 建造、防御、步兵、战车四类标签，双列 cameo（图像 90×72，控件 96×78），保留价格、中文名称/需求提示、生产时钟和队列数量。房间、训练、建造/生产、维修/出售、编组与录像入口均保留。
- 部署页改为暗色金属与红警标题，移除原先大面积绿色样式。

美术来自 [原版资源仓库的固定版本](https://github.com/toarrntnz/ts-redalert2-assets/tree/acfa5b834899e7fab4c8499ccb4b49c402927b44)。精确条目、来源、散列和转换方式见 [美术来源](../Assets/SOURCES.md)。游戏逻辑和格式转换器为独立实现，没有引入第三方 RTS 实现。

## 验证结果

- 普通 `dotnet build RedAlert.csproj --no-restore` 成功，0 警告、0 错误。顺便修正迁移构建缓存后旧 `obj/bin` 被源码 glob 收集导致的重复程序集属性问题。
- [美术完整性检查](classic-art-integrity.json) 通过：269 个源文件散列、782 个 PNG、43 个界面/景物图集、410 个 TMP 子块。每个地表的 900 字节源索引、输出二进制、PNG 每个颜色与透明外边逐项一致。
- TMP 转换工具 1975 项格式与错误输入自测通过；真实原版 TMP 全部转换成功。
- [UI 输入与回放回归](classic-ui-regression.json) 通过：240 ticks、18 条命令接受、0 拒绝，选择、移动、编组、生产、建造、取消及回放重演通过。状态散列仍为 `c6e9e1d5f7e48c65`，内容指纹仍为 `d1493b9340acc921`。
- 原生编辑器会话启动新版程序集，在 OpenHarmony / Mobile Vulkan 1.3.309 / Maleoon 935 上采集 2090×1306 实际帧缓冲。[运行记录](classic-style/runtime.json) 显示战场矩形 `(0,0,1188,900)`、侧栏 `(1188,0,252,900)`，雷达、6 个原版纹理按钮与可见生产图标均位于视口内。原生窗口中切换“战车”标签后，5 个苏军战车图标正常生成。

## 仍有差异

地图布局仍由种子生成，尚未复刻原版手工地图、完整高度/悬崖/岸线自动拼接、原版光照与全部特效；侧栏底部也保留原型必需的紧凑操作按钮。本轮完成原始素材接入、布局与真实绘制检查，当前模型没有图像输入能力，未声称逐像素美术审查或完全一致的原版还原。
