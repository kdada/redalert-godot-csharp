# 本轮菜单、建造与对局体验改造

2026-10-18，规则版本 `command-alpha-5`。按要求并行实现，只执行编译和本轮必要的短检查，不重复执行旧完整回归。旧录像的规则指纹与新版不一致时会被明确拒绝。

## 已实现行为

- 地图预览：纯 C# 工作线程生成实际地图和 RGBA 像素，六种种子以内的共享缓存，最多两个生成器并行；主线程只创建纹理并绘制一次地形纹理及出生点。种子替换、离开页面与释放控件不会让旧结果覆盖新预览。真实单机及 ENet 开局的 World/地图创建同样移至后台，完成后由主线程接管；每局使用独立可变世界。
- 菜单：保留现有原始按钮三帧素材，增加约 160–250 ms 的面板／按钮进入、悬停与按压动效。下拉列表、弹出菜单背景完全不透明。动效时间是独立实现，未声称逐像素还原原作。
- 音频：两段新编写的工业／军事风格循环音乐、20 种不同的合成音效；分别进入 Music、Effects、Voice 音量总线。Voice 当前播放选择、命令与状态的无线电／提示音，不含冒充原版的人声录音。音乐跨菜单重建保留，音效使用固定数量播放器和已加载片段。未导入的源目录可直接解码 WAV；无头模式默认不实际播放。
- 战斗效果：炮弹飞行／烟迹、巨炮抛物线、天启双炮、步枪与狙击命中、电磁电弧、狗攻击、爆炸碎片与烟雾分别表现。炮口位置近似；独立爆炸图集与保留的原始狗攻击帧并用。视觉飞行不改变规范伤害结算时间；捕获与绘制都遵守当前视野，效果数量和绘制预算有限制。
- 建筑：点击右侧图标预付准备，进度结束显示“就绪”，再次点击才进入选址；合法放置不再扣费，随后用原始 buildup 帧快速建起，标准为 20 tick（1 秒），缺电时放慢。非法位置保留就绪建筑；右键图标或选项中的取消建筑准备会全额退款。一次准备一个建筑；丢失必需前置时暂停准备。队列状态、放置时长均进入稳定哈希与录像；内置 AI 和外部 AI API 已适配。
- 聊天：Enter 开所有人频道，Shift+Enter 开队友频道；输入框位于战场下方中间。Enter 发送，Esc 取消当前输入，下一次 Esc 才打开作战菜单。
- 淘汰与结束：失去所有仍存活建筑即失败（按“所有建筑”的字面要求，围墙也计入）；失败／投降当步销毁己方所有单位和建筑，清除建筑准备并释放占地。战败后立即全图观战，禁止作战命令，仍可移动镜头和使用小地图。仅剩一个队伍时结算，显示中央结果菜单。ENet 淘汰者继续接收规范 tick；结束时确认最终哈希。
- Esc：中央菜单提供返回战场、保存录像、投降、结束游戏；观战时隐藏投降。单机打开菜单时暂停，局域网继续；结束游戏返回部署，房主结束会关闭房间。

## 必要短检查

```zsh
dotnet build RedAlert.csproj --no-restore -v:minimal
dotnet run --project Tests/RedAlert.Tests.csproj -- --experience --report=Reports/experience-simulation.json
godot --headless --path . -- --experience-check --report=Reports/experience-ui.json
```

模拟定向检查限于新建造、退款、缺电、即时清场、围墙存活、队伍胜负和 40 tick 录像；不运行原 25 项测试及八人长时间回放。无头界面检查限于异步预览、22 个 WAV 的原生解码、实际聊天／Esc 按键与三席位 ENet 开局／淘汰／结束。
