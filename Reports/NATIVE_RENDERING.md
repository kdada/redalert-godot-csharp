# 鸿蒙原生图形运行验证

验证日期：2026-10-18（Asia/Shanghai）。本轮使用图形 Godot Editor App 启动实际游戏窗口，补充此前的 headless 验证。

## 运行环境与连接

| 项目 | 实际结果 |
| --- | --- |
| Godot | 4.7.2 stable mono custom build |
| 显示服务 | OpenHarmony |
| 渲染器 | Mobile / Vulkan 1.3.309 |
| GPU | Maleoon 935 |
| 逻辑视口 | 1440 × 900 |
| 实际帧缓冲 | 2090 × 1306 |
| DSH Godot Control | 0.1.2，160 个文件通过安装脚本 SHA-256 一致性检查 |
| 编辑器 / 游戏 PID | 10976 / 13452（本轮会话） |
| 红警控制会话 | `redalert-godot-csharp@80d0c4c9ab1c8b0a` |

插件来自本机维护的 `oheco/dsh-godot-control`，完整树摘要为 `4677e0ddd62e5f7e30bdc07bc1ea167ea6348dc750b487e3be685cbb68a46b35`。已在 [工程配置](../project.godot) 中启用插件及其游戏调试辅助节点。配对凭据仅保存在 Git 忽略的 Godot 元数据中，不写入本报告。

命令行阶段的 Godot 缓存原来是指向终端 App 私有缓存的软链接。本轮将工程的 Godot 缓存改为常规目录并保留原缓存，使图形 App 与终端能够共同读取工程元数据和托管程序集。

## 已验证的实际行为

- 通过图形编辑器运行主场景，调试辅助节点进入 live 状态。
- 美国、俄罗斯、法国、英国分别启动四人单机训练场，均成功生成原生窗口截图。为保留开局状态，拍摄开局截图时暂停模拟，拍摄结束后恢复部署界面并解除暂停。
- 在实际游戏进程调用资源与 UI 检查，加载 27 套 SHP 图集、10 套车辆图集、75 张运行时纹理。原有检查函数的日志前缀仍为 `HEADLESS UI STRUCTURE VERIFIED`；本轮调用环境由显示服务、GPU 和截图证据单独确认。
- 20 个代表性中文字符经实际 TextServer 排版，均取得有效字体 RID 和非零字形索引，缺失字形数为 0。默认字体文件的 `has_char` 返回 false，系统字体回退仍能正常提供字形，不能仅凭该返回值判定中文缺字。
- 战场矩形为 `(0,55,1140,803)`，雷达矩形为 `(1152,99,276,160)`；保存录像、返回部署、建造/步兵/战车、停止/维修/出售、投降按钮均位于逻辑视口内。部署界面的 6 个主要按钮也均位于视口内。
- 战场运行中一次采样约 30 FPS、993 次绘制调用；部署界面末次采样 60 FPS。它们是该设备、该场景下的瞬时读数，不构成持续帧率或大规模战斗性能保证。
- 最终运行 `r337977-2` 的游戏日志只有辅助节点注册和资源检查信息，无游戏错误。此前一次临时诊断表达式编译失败，已在重新启动本工程游戏后修正；不是游戏源码编译失败。
- 安装并启用插件后重新运行 headless UI 与输入验收：240 ticks、18 条接受命令、0 拒绝命令，选择/移动/编组/生产/建造/取消全部通过，回放重演通过，状态散列仍为 `c6e9e1d5f7e48c65`；进程退出码 0，无引擎错误或资源泄漏日志。结果见 [插件安装后的兼容性记录](native-render/headless-ui-after-addon.json)。
- 验证完成后，游戏保留在可操作的部署页，点击“进入四国训练场”即可试玩。

原始运行信息见 [运行记录](native-render/runtime.json)。此前的模拟、多人网络和回放结果见 [headless 验证报告](VALIDATION.md)；本轮没有将单机图形验证扩大为八人图形联机或公网验证。

## 验证边界与启动方式

当前会话模型不支持直接读取图像。本轮确认了原生 GPU 绘制、实际截图、字形排版、布局边界和运行日志，未完成逐像素美术审查；不据此声称所有遮挡、动画和美术细节均已人工确认。

系统拒绝了本次通过 HDC 请求创建新应用实例的启动方式（10108101）。本轮改用 Godot 已有的原生进程启动通道打开另一个编辑器，没有关闭原有宝可梦工程。新编辑器为附属进程，退出其父游戏进程可能同时结束这个编辑器；工程文件和截图已经保存。后续可在图形项目管理器中导入 [工程入口](../project.godot) 后打开，再按 F5 运行。
